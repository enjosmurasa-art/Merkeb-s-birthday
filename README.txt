MERKEB BIRTHDAY WEBSITE

Files:
- index.html: website content
- style.css: pink design and animations
- script.js: buttons and floating hearts

PREVIEW IN ACODE:
1. Extract the ZIP into a folder.
2. Open the folder in Acode.
3. Open index.html.
4. Use Acode's Preview button/menu to open it in a browser.
5. Check both buttons and scroll the page on a phone-sized screen.

PUBLISH FREE WITH NETLIFY:
1. Keep index.html, style.css, and script.js together in one folder.
2. Open https://app.netlify.com/drop in Chrome.
3. If needed, sign up or sign in to Netlify.
4. Upload/drag the folder containing these three files (if folder upload is not offered, ZIP the three files and follow the upload page's current instructions).
5. Wait for Netlify to deploy it and copy the generated public URL.
6. Open the URL on your phone to test it before sending it.

SEND ON INSTAGRAM:
1. Open Instagram and go to Merkeb's DM.
2. Send a short message such as:
   "Buka 😭💗 I made a little birthday surprise just for you. Open this 🎂👇"
3. Paste your live Netlify URL.

CUSTOMIZE:
Edit the birthday letter inside index.html. You can change the text, emojis, and colors. If you change file names, update the stylesheet/script references in index.html too.

NOTES:
- The fonts load from Google Fonts when internet is available; fallback fonts still work offline.
- This project does not collect or store personal information.
- A free hosting provider may change its interface, so follow the current prompts shown on its site.


BUTTON FIX:
1. Upload/commit index.html, style.css, and script.js together to your published site.
2. Keep all three files in the same folder.
3. Refresh the live website. If the old version remains, open it in a private/incognito tab.
4. Test the birthday letter, surprise, Lamborghini, and villa buttons.
